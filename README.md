# Flavors

Flavors are userscripts that restyle web apps. This repo holds every flavor: its code, every released
version, its screenshots and its changelog. The site at
[flavors.shadowarcanist.com](https://flavors.shadowarcanist.com) is built from this repo.

To install a flavor, use the site: every flavor page has an Install button, the full code and the
changelog.

## Links

- [Website](https://flavors.shadowarcanist.com): browse, preview and install flavors
- [Install guide](https://flavors.shadowarcanist.com/guide): install, update and remove a flavor
- [Notices](https://flavors.shadowarcanist.com/notices): read these before you install a flavor
- [FAQ](https://flavors.shadowarcanist.com/about#faq): requests, contributions and updates
- [Making flavors](docs/making-flavors.md): how this repo is laid out, and its rules

## Contributing

Pull requests are turned off for outside contributors. To report a bug in a flavor, open an issue.
